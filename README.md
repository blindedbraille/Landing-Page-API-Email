# FORM. | An Independent Art Gallery

FORM. is a responsive landing page for an independent experimental art gallery that brings contemporary art into unconventional pop-up spaces across Toronto.

The website combines minimalist editorial design, atmospheric gradients, glassmorphism, and interactive artwork displays to create an immersive digital gallery experience.

## Exhibition: After the Light

*After the Light* explores the relationship between light, movement, space, and perception through experimental light painting and long-exposure photography.

The landing page promotes the upcoming exhibition and encourages visitors to subscribe for exclusive early access and exhibition announcements.

## Project Objective

The objective was to design and develop a visually engaging, conversion-focused landing page that balances artistic expression with usability, accessibility, and clear communication.

## Design Direction

- Minimalist and contemporary editorial design
- Dark, atmospheric colour palette
- Liquid glass-inspired interface elements
- Manrope typography
- Generous negative space and visual hierarchy
- Experimental photography
- Smooth, intentional micro-interactions

## Features

- **Hero Carousel:** Automatically rotating artwork with dynamic titles, artist captions, progress indicators, and manual navigation.
- **Selected Works:** Animated artwork carousel featuring smooth card-shuffling transitions.
- **Featured Artists:** Interactive artist biographies with dynamic artwork previews.
- **About FORM.:** Expandable company mission and information.
- **Subscription Modal:** Interactive registration form with validation, success, and error states.
- **Newsletter:** Email subscription form integrated with EmailJS.
- **Cursor Glow:** Interactive gradient lighting that responds to cursor movement.
- **Responsive Design:** Adaptive layouts for desktop, tablet, and mobile devices.

## Running Locally

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Launch `index.html` using the Live Server extension or a local web server.
4. Configure EmailJS credentials and template variables if using a different EmailJS account.

## EmailJS Integration

EmailJS connects the subscription modal and newsletter form to an email service using JavaScript and an API, without requiring a custom backend.

The forms include email validation, submission feedback, and confirmation states.
